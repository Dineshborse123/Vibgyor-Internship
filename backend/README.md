# NovaShop - Next-Gen Retail Backend

This is the Spring Boot backend API for the NovaShop e-commerce application. It handles user authentication, product management, cart operations, checkout processing, and review handling.

## Tech Stack
- Java 17
- Spring Boot 3
- Spring Data JPA
- Hibernate
- MySQL Database

## Features
- Complete RESTful API architecture
- Secure entity relationships (One-to-Many, Many-to-One)
- Robust transaction management for orders
- Payment mock APIs

## Setup
1. Configure your MySQL database credentials in `src/main/resources/application.properties`
2. Run `mvn clean install`
3. Run `mvn spring-boot:run`

Ready for deployment.
